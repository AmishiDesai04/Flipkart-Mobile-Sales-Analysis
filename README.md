# Flipkart-Mobile-Sales-Analysis

An interactive Tableau dashboard project that analyzes mobile phone listings on Flipkart to uncover trends in brand performance, pricing, customer ratings, and product features. This case study was created as part of a Business Information Visualization & Analysis course.

## Overview

This project explores mobile sales data using Tableau to answer key business questions such as:

- Which brands dominate Flipkart in listings and ratings?
- Do technical specs like RAM, battery, or camera affect price and ratings?
- Which brands provide the best value for money?

## Dataset

- **Source**: [Kaggle - Flipkart Mobile Dataset](https://www.kaggle.com/datasets/shubhambathwal/flipkart-mobile-dataset)
- **Size**: 430 rows × 16 columns
- **Attributes**: Brand, Model, Color, Processor, Screen Size, RAM, ROM, Cameras, Battery, Price, Ratings, Sales, and Discounts.

## Key Insights

- **Realme** has the highest number of listings.
- **Black** and **Blue** are the most common phone colors.
- Phones with **higher RAM** and **battery** tend to cost more.
- **Poco**, **Realme**, and **Xiaomi** offer the best value for money.
- **Apple** leads in user satisfaction despite fewer listings.

## Tools Used

- **Tableau** – for data visualization

## Visualizations

The dashboard includes:
- Brand-wise listings and rating comparisons
- Price distribution and outliers
- Correlation between specs (RAM, battery, cameras) and price
- Processor and color trends
- Value-for-money brand analysis
